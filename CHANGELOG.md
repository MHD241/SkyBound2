# Skybound 2.0

## 2.0.0 — clean rebuild
- Replaced the old patched single-file simulator with a new modular codebase.
- Added a dependency-free raw WebGL renderer.
- Added new start flow, gate map, hangar and aircraft selection.
- Added a completely new visual design.
- Added three-airport world including restricted Supersonic Island.
- Added JX-90, JX-200 and custom Concorde geometry.
- Added manual ATC frequencies and multiple ATC services.
- Added autopilot and Auto Land.
- Added forgiving landing logic.
- Added interactive follow minimap.
- Added moving city traffic, reduced rapid NPC air traffic, engine audio and optional ambient music.
- Added restricted-airspace interceptor behaviour.
