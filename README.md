# Skybound 3D — Milestone 1

Fresh WebGL 2 codebase. No old Skybound game code, no CDN, no npm/build step, no service worker.

## Run on GitHub Pages
Upload the contents of this folder to the repository root. `index.html` is the entry point.

## Controls
- W / S: throttle up/down
- Arrow Up / Down: pitch
- Arrow Left / Right: bank
- A / D: rudder / ground steering
- C: chase/cockpit camera
- Drag mouse: orbit chase camera
- Mouse wheel: chase zoom
- R: reset aircraft

## Milestone 1 scope
- custom WebGL 2 renderer
- procedural 3D island + ocean
- airport with runway, taxiway, terminal, gates, hangars, control tower, approach lights
- detailed procedural JX-200 with swept wings, twin engines, windows, landing gear and lights
- flight physics, ground roll, takeoff and landing
- chase and cockpit cameras
- lighting, fog and animated ocean

This is deliberately the foundation only. ATC, world map, passenger mode, Supersonic Island and larger city systems are later milestones after this visual/flight baseline is approved.
